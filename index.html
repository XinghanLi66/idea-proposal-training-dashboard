Benchmark result dashboards for research-idea proposal generation (SFT + RL across model families).

Each dashboard is a faithful task × arm results matrix: every scored cell drills down to the problem, baselines, the proposer (master) prompt and generated proposal, the worker's implementation prompt and final code, and per-seed scores. Worker = Claude fable-5 (opus-4-8 on protein tasks). Headline: frontier proposers (Claude Fable 5, GPT-5.5) land mid-pack — beaten by several trained checkpoints.
